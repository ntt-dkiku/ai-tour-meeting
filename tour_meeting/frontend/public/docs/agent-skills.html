What it covers

The skill condenses everything an agent needs to work with this repo, verified against the implementation:

  • Deployment — make targets, API keys in docker/.env, ports, and local LLM serving (Ollama / vLLM options and how server URLs resolve).
  • Running scripts and experiments — make run SCRIPT=..., and the gen-meetings → run-meetings → post-eval batch pipeline.
  • Python API — build_meeting with every participant/meeting setting and its default, the event stream, results (final_route, analytics), the human seat, and external-system integration.
  • Formatting — model names need litellm-style prefixes (openai/gpt-5.2, ollama/{i}/{model}, vllm/{i}/{model}).
  • Testing — pytest tests/ runs against mocked LLMs, no API keys needed.
