Overview

Start here if you are new to the project. The docs walk you through launching the app, using the GUI, understanding turn-taking, and changing the code with confidence.

Open Quick Start GUI Guide Developer Guide

Who is this for

For first-time users

Launch the stack, enter your keys, open the GUI, and run a sample meeting.

For daily use

Use the GUI guide when you want to set up participants, adjust meeting settings, or inspect logs.

For custom changes

Use the developer guide when you need to change the engine, update the API, or run tests.

Suggested path

  1. Read Quick Start to get a meeting running.
  2. Move to GUI Guide when you want to work from the browser app.
  3. Use Meeting Flow to understand how turns and cycles behave.
  4. Finish with Developer Guide when you want to customize or test the project.

What this project does

Meeting planning

Participants discuss routes, refine proposals, and settle on a meeting plan.

GUI control

The browser app is the main place to create meetings, edit settings, and watch the log stream.

Developer tools

The repository also includes test targets, a Python entry point, and the files that shape the engine.
