Overview

AI Tour Meeting is a group travel planning framework powered by multiple LLM agents. The agents collaborate with each other to find an itinerary that satisfies their constraints and preferences through natural language discussions. This framework enables easy and flexible orchestration of such discussions by providing interfaces for configuring agent personas, discussion workflows, monitoring, etc.
