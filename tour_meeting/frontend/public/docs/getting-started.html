Quick Start

Use this page when you want the fastest path from a fresh checkout to a running meeting. The goal is simple: start the stack, open the GUI, add the keys you need, and launch a meeting that you can actually work with.

1. Start the stack

  1. Run make up to start the backend and frontend.
  2. Open the GUI in your browser after the containers are ready.
  3. Check that the sidebar, meeting settings, and log viewer are visible before you continue.

2. Add the keys you need

Open Settings and enter the API keys for the providers you plan to use. If you are trying the app with a local model, make sure the local model settings match the environment you have running.

3. Create your first meeting

Start from scratch

Create a new meeting, add participants, and pick a turn rule that matches the conversation style you want.

Use a random sample

Generate a sample meeting when you want a working example without assembling everything by hand.

Watch the flow

Keep the log viewer open so you can confirm who speaks next and whether balanced turns are behaving as expected.

Switch to the GUI guide

Use the GUI guide when you want a fuller walkthrough of the meeting settings, sidebar, and participant controls.

4. Try the Python CLI

The repository also ships with small Python examples under examples/ for direct use of the meeting engine. They are handy when you want to understand the flow from code or run a quick experiment without opening the browser. 

make run SCRIPT=examples/barcelona.py
