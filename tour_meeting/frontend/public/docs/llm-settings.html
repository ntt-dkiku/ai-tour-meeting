LLM settings

AI Tour Meeting needs a model provider before AI participants can speak. Configure the provider, model, and key that match your environment.

Choose a provider

Select the provider you want the participants to use. Hosted providers need their API key. Local providers need the local runtime to be up and reachable from the backend container or process.

Set keys

Open Settings in the GUI and add the key for the provider you selected. If random sampling or meeting start reports that no API key is configured, return to Settings and save the missing key before trying again.

Local models

Local models are useful for development and private experiments. Confirm the model server is already running, then use the model name and provider prefix expected by the backend configuration.
